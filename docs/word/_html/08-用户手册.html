用户手册

项目名称 商品推荐系统（Product Recommendation System）
文档版本 v1.0

1. 系统简介

本系统是一个带个性化推荐的电商演示平台，包含两类使用者：

角色 能做什么 入口
游客 浏览商品、搜索筛选、查看详情与评价、看热门推荐 `/`
普通用户 游客全部能力 + 个性化推荐、购物车、下单、取消订单、发表评价 注册/登录后
管理员 普通用户能力 + 商品/类目/用户/订单管理 + 查看推荐评测指标 `/admin`

推荐功能怎么来的（一句话版）： 系统把你「浏览、点击、加入购物车、评分、购买」这五类行为按强度加权记录下来， 用它们计算「和你兴趣相近的人还看了什么」（UserCF）与「和这件商品常被一起看的商品」（ItemCF）， 不足时用热门商品兜底，所以推荐位永远不会空。

2. 登录与注册

2.1 演示账号（初始化演示数据后可直接使用）

角色 用户名 口令
管理员 `admin` `admin123`
普通用户 `user001` `123456`

2.2 注册新账号

  1. 右上角点「注册」。
  2. 用户名 4–20 位，密码两次输入必须一致。
  3. 注册成功后自动登录并跳回原页面。

2.3 登录

  • 右上角点「登录」→ 输入用户名与口令 → 成功后右上角显示昵称。
  • 登录状态保存在浏览器本地，关闭页面再打开仍保持登录；点「退出」清除。

提示：如果在其他页面点了需要登录的功能（如加入购物车），系统会先跳到登录页， 登录成功后自动回到原页面。

3. 购物端

3.1 首页 `/`

区块 说明
为你推荐 仅登录后出现，基于你的行为计算，卡片底部绿色标签是推荐理由
热门推荐 所有人都能看到，按近 30 天热度排序，用于冷启动与游客浏览

未登录时「为你推荐」区域不显示，页面顶部会提示登录。

3.2 商品列表 `/products`

  • 关键字：按商品名称搜索，回车或点「搜索」生效。
  • 类目：两级类目下拉，选一级类目会包含其下所有商品。
  • 价格区间：填最低价/最高价，任一可留空。
  • 排序：默认（销量优先）、销量优先、价格从低到高、价格从高到低。
  • 重置：一键清空所有条件。
  • 列表只显示上架商品；已被管理员下架的商品不会出现。

3.3 商品详情 `/products/:id`

页面自上而下分为四块：

  1. 商品信息：名称、副标题、售价/原价、类目、销量、库存、描述。
  2. 加入购物车：选择数量（不超过库存）→ 点「加入购物车」→ 右上角提示成功。
  3. 相似推荐：ItemCF 计算的「经常被一起浏览/购买」的商品，最多 8 条，点卡片跳转详情。
  4. 商品评价：
    • 上方是发表评价表单：选择 1–5 星评分，可写最多 500 字内容。
    • 提交后立即出现在列表首条；同一件商品每人只能评价一次，重复提交会提示「您已评价过该商品」。
    • 下方按时间倒序展示所有评价，分页显示。

打开详情页本身会记录一次「浏览」行为，登录状态下才算数，用于后续推荐。

3.4 购物车 `/cart`（需登录）

操作 说明
修改数量 直接改数字，自动保存；超过库存会被拒绝
勾选 只有勾选的商品参与下单
删除单条 行尾「删除」
清空购物车 卡片右上角「清空」
合计金额 页面顶部显示已勾选商品合计

3.5 订单 `/orders`（需登录）

提交订单

  1. 先在购物车勾选商品。
  2. 订单页填写收货人、手机号（11 位）、收货地址。
  3. 点「提交订单」→ 返回订单号，列表自动刷新。

下单时系统会：扣减库存、累加销量、写入订单明细（商品名与价格快照）、 记录一次「购买」行为、清空已结算的购物车条目。

订单列表

列 说明
订单号 业务唯一编号，可用于沟通
商品 明细摘要，如「演示商品 12×2」
金额 订单总金额
状态 待支付 / 已支付 / 已发货 / 已完成 / 已取消
详情 弹窗展示收货信息与完整明细
取消 仅「待支付」「已支付」可取消，取消后库存回滚

4. 管理端 `/admin`（需管理员）

管理员登录后顶部导航出现「后台」，普通用户访问会被提示「仅管理员可访问后台」。 后台分为 5 个页签。

4.1 概览

  • 五张统计卡：用户数、商品数、订单数、行为数、总销量。
  • 推荐效果离线评测：点「运行评测」后返回
    • Precision（准确率）：推荐出去的商品有多少被用户真实行为命中
    • Recall（召回率）：用户真实感兴趣的商品有多少被推荐出来
    • F1：二者的调和平均
    • 覆盖率：推荐结果覆盖了多少比例的商品（括号内为 覆盖数/商品总数）
    • 参评用户数、平均流行度
  • 评测采用留出法：80% 行为做训练、20% 做测试，TopN=10，指标随数据变化而变化。

4.2 商品管理

操作 说明
查询 支持商品名称关键字 + 上架状态（全部/上架中/已下架）
新增商品 填名称、类目、价格、库存等，保存后立即出现在列表
编辑 修改任意字段并保存
上架 / 下架 下架后前台列表与详情不再可见（详情会提示「商品不存在或已下架」）
删除 逻辑删除，前台不可见；历史订单明细保留快照，不受影响

后台列表包含已下架商品，因此不存在「下架后再也找不到」的问题。

4.3 类目管理

  • 展示两级类目树，默认全部展开。
  • 「新增一级类目」：父级为「无」。
  • 行内「新增子类目」：只能挂在一级类目下（本项目限定两级）。
  • 删除规则（防止数据被孤立）：
    • 有子类目的类目不能删；
    • 类目下仍有商品时不能删。

4.4 用户管理

  • 按用户名或昵称搜索，分页查看。
  • 列表展示角色与状态（正常/已禁用），不展示任何口令信息。
  • 「禁用」后该用户立即无法登录，登录会提示账号已被禁用；「启用」可恢复。
  • 管理员账号自身不可被禁用（按钮置灰）。

4.5 订单管理

  • 按状态筛选，分页查看全平台订单。
  • 「变更状态」下拉可把订单改为待支付/已支付/已发货/已完成/已取消：
    • 改为「已支付」时，若订单此前没有支付时间，系统自动补记；
    • 已取消的订单不可再变更。
  • 列表中的商品摘要来自订单明细快照，商品改名或删除不影响历史展示。

6. 常见问题

问题 原因与处理
首页「为你推荐」是空的 新账号还没有行为数据（冷启动），先浏览/加购几件商品再刷新
推荐的都是热门商品，感觉不个性 行为太少，算法近邻不足时会自动兜底为热门；多用几次会逐步变化
加入购物车提示未登录 该功能需要登录，按提示登录后会回到原页面
提交评价提示「您已评价过该商品」 每人每件商品只能评价一次
下单提示「购物车为空」 购物车没有勾选任何商品
下单提示库存不足 商品库存少于购买数量，减少数量或换商品
取消订单后库存没恢复 取消是事务操作，刷新页面确认；若状态已变为「已取消」库存必然已回滚
后台看不到某个商品 在商品管理里把状态切到「全部状态」再查询
修改商品状态后前台没变化 前台有缓存与浏览器缓存，刷新页面即可
管理员账号被禁用后登不进去 用另一个管理员账号启用；演示环境直接重置数据

7. 迭代新增功能使用说明

7.1 购物端

功能 入口与操作
结算下单 购物车勾选商品 → 「去结算」→ 弹窗内选收货地址、支付方式（支付宝/微信/银行卡）→ 「提交订单」→ 跳转收银台 → 「确认支付」。订单状态变为「已支付」才算下单完成
支付方式 下单时选定，收银台可临时更换；列表与详情均展示支付方式与支付时间
查看物流 订单详情展示配送方（顺丰/邮政/中通等）、物流单号、发货时间
确认收货 已发货订单点「确认收货」即完成交易；不确认的话发货满 7 天系统自动确认
消息通知 顶栏铃铛显示未读数；支付、发货会收到通知，点击跳转订单页；支持全部已读
订单追溯 订单详情底部的时间轴记录每次状态变更（谁、何时、从什么状态改成什么）

7.2 管理端

功能 入口与操作
发货 订单管理 → 「发货」→ 选择配送方 → 单号自动生成（可改写、可重新生成）→ 确认发货
确认收货 已发货订单在发货满 7 天后出现「确认收货」按钮；未到期显示灰色并提示剩余天数
订单操作 按状态只显示合法操作：待支付-取消；已支付-发货/取消；已发货-确认收货（满 7 天）；已完成/已取消-无操作
刷新推荐模型 概览页「推荐效果离线评测」卡片支持手动运行；批量导入行为数据后可调用 `POST /api/admin/recommend/refresh` 让推荐立即反映新数据
类目管理 支持三级类目：表格按层级展示、三级后不可再加；新增时下拉自动缩进并提示将创建的层级
