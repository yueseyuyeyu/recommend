## 1. 部署架构

```
┌──────────────┐    /api 反向代理     ┌────────────────────┐      JDBC       ┌──────────────┐
│  浏览器       │ ───────────────────▶ │  Nginx / Vite 代理  │ ─────────────▶ │ Spring Boot  │
│ (Vue 3 SPA)  │                      │  (5173 或 80)       │                │   :8080      │
└──────────────┘                      └────────────────────┘                └──────┬───────┘
                                                                                    │
                                                                              ┌─────▼──────┐
                                                                              │  MySQL 8   │
                                                                              │ recommend_db│
                                                                              └────────────┘
```

前端为纯静态 SPA，后端为无状态 JWT 服务，两者可分别部署与水平扩展。

## 3. 配置项（全部走环境变量）

后端配置文件 `recommend-server/src/main/resources/application.yml` 中不含任何明文口令与密钥：

| 环境变量      | 必填 | 默认值            | 说明                                        |
| ------------- | ---- | ----------------- | ------------------------------------------- |
| `DB_HOST`     | 否   | `localhost`       | MySQL 主机                                   |
| `DB_PORT`     | 否   | `3306`            | MySQL 端口                                   |
| `DB_NAME`     | 否   | `recommend_db`    | 库名                                         |
| `DB_USERNAME` | 否   | `root`            | 数据库账号                                   |
| `DB_PASSWORD` | **是** | 空              | 数据库口令                                   |
| `JWT_SECRET`  | **是** | 内置占位值      | 签发令牌的密钥，**长度 ≥ 32 字节**，生产必须覆盖 |
| `SERVER_PORT` | 否   | `8080`            | 后端端口（改 `server.port`）                 |

推荐做法：在项目根目录建 `.env`（已在 `.gitignore` 中忽略，模板见 `.env.example`），
或直接在运行配置/启动脚本里注入。

推荐算法参数（`recommend.*`）见 `application.yml`，常用项：

| 参数                  | 默认 | 含义                             |
| --------------------- | ---- | -------------------------------- |
| `default-top-n`       | 10   | 推荐位默认条数                   |
| `neighbor-k`          | 20   | 近邻数量 K                       |
| `popularity-penalty`  | 0.0  | ItemCF 热门惩罚因子 α            |
| `user-cf-weight`      | 0.6  | 混合推荐中 UserCF 权重           |
| `item-cf-weight`      | 0.4  | 混合推荐中 ItemCF 权重           |
| `hot-days`            | 30   | 热门统计时间窗口（天）           |
| `enable-cache`        | true | 是否缓存推荐结果                 |
| `cache-ttl-seconds`   | 1800 | 缓存有效期                       |

## 4. 数据库初始化

### 4.1 建库建表

```powershell
cd D:\桌面\商品推荐系统
& "D:\mysql\mysql-8.0.27-winx64\bin\mysql.exe" -u root -p `
    --default-character-set=utf8mb4 -e "source sql/schema.sql"
```

`schema.sql` 会创建库 `recommend_db`（utf8mb4）与 8 张表、17 个索引。
脚本内含 `DROP TABLE IF EXISTS`，**重复执行会清空数据**。

### 4.2 灌演示数据（两种方式，二选一）

**方式 A：纯 SQL（推荐，无需编译后端）**

```powershell
& "D:\mysql\mysql-8.0.27-winx64\bin\mysql.exe" -u root -p `
    --default-character-set=utf8mb4 recommend_db -e "source sql/seed.sql"
```

> 命令行提示 `Access denied` 时不要反复重试：如果 IDEA 的 Database 面板能连上库，
> 直接对 `recommend_db` 右键「Run SQL Script」选 `sql/seed.sql` 执行，效果完全一样。

注意：`seed.sql` 使用了**临时表**做数字序列生成，必须在同一个连接里整文件执行
（IDEA 用「Execute script / 执行脚本」，命令行用 `source`），不要拆成单条语句执行。

执行完会输出 8 行自检结果，正常应为
`category 40 / user 201 / product 500 / behavior 5000 / orders 800 / order_item ~1600 / review 600 / cart 3`。

**方式 B：Java 生成器（可自定义规模）**

```powershell
cd recommend-server
$env:JAVA_HOME = 'D:\java17'
$env:DB_PASSWORD = '你的数据库口令'
.\mvnw.cmd exec:java "-Dexec.args=--reset"          # 默认 200 用户 / 500 商品 / 5000 行为 / 800 单 / 600 评价
.\mvnw.cmd exec:java "-Dexec.args=--reset --users=50 --products=100"
```

两种方式都会清空 8 张业务表后重建，**不要对着生产库执行**。

### 4.3 演示账号

| 角色     | 用户名    | 口令       | 说明               |
| -------- | --------- | ---------- | ------------------ |
| 管理员   | `admin`   | `admin123` | 后台 `/admin`      |
| 普通用户 | `user001` | `123456`   | 演示个性化推荐     |

口令在库中以 BCrypt(10) 哈希存储，登录时由 `BCryptPasswordEncoder` 校验。

## 5. 后端部署

### 5.1 开发模式启动

```powershell
cd D:\桌面\商品推荐系统\recommend-server
$env:JAVA_HOME    = 'D:\java17'
$env:DB_PASSWORD  = '你的数据库口令'
$env:JWT_SECRET   = -join ((1..48) | ForEach-Object { [char](Get-Random -Min 33 -Max 126) })
.\mvnw.cmd spring-boot:run
```

### 5.2 打包与运行 jar（单机生产）

```powershell
cd D:\桌面\商品推荐系统\recommend-server
$env:JAVA_HOME = 'D:\java17'
.\mvnw.cmd -B clean package          # 产出 target/recommend-server-1.0.0.jar

$env:DB_PASSWORD = '你的数据库口令'
$env:JWT_SECRET  = -join ((1..48) | ForEach-Object { [char](Get-Random -Min 33 -Max 126) })
java -jar target\recommend-server-1.0.0.jar --server.port=8080
```

Linux 下建议用 systemd 托管：

```ini
[Unit]
Description=recommend-server
After=network.target mysql.service

[Service]
User=app
WorkingDirectory=/opt/recommend
Environment=DB_HOST=127.0.0.1
Environment=DB_NAME=recommend_db
Environment=DB_USERNAME=recommend
Environment=DB_PASSWORD=__从密钥管理注入__
Environment=JWT_SECRET=__从密钥管理注入__
ExecStart=/usr/bin/java -Xms512m -Xmx1g -jar /opt/recommend/recommend-server-1.0.0.jar
Restart=always

[Install]
WantedBy=multi-user.target
```

### 5.3 启动验证

| 检查项        | 方式                                                  | 期望                       |
| ------------- | ----------------------------------------------------- | -------------------------- |
| 端口监听      | `netstat -ano \| findstr :8080`                        | 有 LISTENING               |
| 接口文档      | 浏览器打开 `http://localhost:8080/swagger-ui.html`     | 正常渲染接口列表           |
| 公开接口      | `GET http://localhost:8080/api/recommend/hot?topN=3`   | 返回 `code=0` 与 3 条商品  |
| 登录          | `POST /api/auth/login`，body `{"username":"user001","password":"123456"}` | 返回 `token` |
| 鉴权生效      | 不带 token 访问 `GET /api/cart`                        | 返回 `code=401` 类错误码   |
| 推荐可用      | 带 token 访问 `GET /api/recommend/home?topN=5`         | 返回 5 条推荐，含推荐理由  |

## 6. 前端部署

### 6.1 开发模式（热更新）

```powershell
cd D:\桌面\商品推荐系统\recommend-web
npm.cmd install          # 首次
npm.cmd run dev          # http://localhost:5173，/api 已代理到 8080
```

> PowerShell 若提示「禁止运行脚本」，用 `npm.cmd` 而不是 `npm`。

### 6.2 生产构建

```powershell
cd D:\桌面\商品推荐系统\recommend-web
npm.cmd install
npm.cmd run build        # 产物在 dist/
```

### 6.3 Nginx 静态托管 + 反向代理

```nginx
server {
    listen       80;
    server_name  recommend.example.com;

    root  /opt/recommend-web/dist;
    index index.html;

    # SPA history 路由：找不到文件时回落到 index.html
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端接口
    location /api/ {
        proxy_pass         http://127.0.0.1:8080/api/;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }

    # 静态资源长缓存（文件名带 hash）
    location /assets/ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

### 6.4 交接注意事项

- 后端开启了 CORS（`CorsConfig`，默认允许 `localhost:5173`）。走 Nginx 同源代理时不会触发跨域；
  若前后端分域部署，需要把前端域名加入 `CorsConfig` 的白名单。
- 前端 `api/http.js` 的 `baseURL` 固定为 `/api`，因此**必须**由代理转发，不允许直连 8080。

## 7. 常见问题（FAQ）

| 现象                                                | 原因与处理                                                                 |
| --------------------------------------------------- | -------------------------------------------------------------------------- |
| 启动报 `Access denied for user 'root'`              | 未设置 `DB_PASSWORD`，或口令含特殊字符需要加引号                             |
| 启动报 `JWT 密钥长度不足` / `WeakKeyException`      | `JWT_SECRET` 不足 32 字节（**中文按 3 字节计**，11 个汉字才 33 字节且实际 29 字节）；改用 48 位 ASCII 随机串，见 5.1 的命令 |
| `mysql` 命令行报 `Access denied ... (using password: YES)`，但 IDEA 里能连 | 命令行口令输错，或客户端编码/粘贴带入特殊字符；直接在 IDEA 的 Database 面板对 `recommend_db` 右键「Run SQL Script」执行 `seed.sql` |
| 启动报 `Unknown database 'recommend_db'`            | 未执行 `sql/schema.sql`                                                     |
| 登录后立刻 401                                      | `JWT_SECRET` 在两次启动间发生变化，导致旧令牌失效；固定该变量               |
| 前台商品列表为空                                    | 数据未灌（执行 `seed.sql`）；或商品全部被下架                               |
| 首页「为你推荐」为空                                | 该用户无行为数据，属冷启动，接口会以热门兜底；检查 `behavior` 表是否有该用户数据 |
| 中文乱码                                            | 客户端连接未用 utf8mb4：加 `--default-character-set=utf8mb4`；IDEA 控制台编码设为 UTF-8 |
| `seed.sql` 执行报 `Table 'tmp_seq' doesn't exist`   | 拆成单条语句执行导致临时表随会话丢失；请整文件执行                          |
| `mvnw` 无法下载依赖                                 | 检查本机 `settings.xml` 的阿里云镜像与本地仓库 `D:\maven-repo` 是否存在     |
| 前端 `npm run build` 提示 chunk > 500 kB            | 仅告警（element-plus 全量引入），不影响运行；需要可改按需引入                |

## 8. 升级与回滚

1. 代码升级：`git pull` → `mvnw -B clean package` → 替换 jar → 重启服务。
2. 表结构升级：新变更先写入 `sql/schema.sql`（保持与代码同版本），生产环境用增量脚本执行，
   **禁止**直接对生产库执行 `schema.sql`（含 `DROP TABLE`）。
3. 回滚：保留上一版本 jar 与数据库备份（`mysqldump -u root -p recommend_db > backup.sql`），
   回滚时先停服务 → 还原库 → 换回旧 jar → 启动 → 按 5.3 验证。

## 9. 安全检查清单

- [ ] `DB_PASSWORD`、`JWT_SECRET` 未写入任何入库文件（`.env` 已被 `.gitignore` 忽略）
- [ ] `JWT_SECRET` 长度 ≥ 32 字节且为随机值（不是内置占位串）
- [ ] 生产库账号不是 `root`，只授予 `recommend_db` 的增删改查权限
- [ ] 数据库端口未对公网开放
- [ ] Nginx 只暴露 80/443，8080 与 3306 仅本机可达
- [ ] Swagger 在生产环境按需关闭（`springdoc.api-docs.enabled=false`）
